# Blog LaTeX Copy Privacy Policy / 隐私政策

## English

Blog LaTeX Copy processes webpage text you select and the LaTeX sources of equations in that selection when you copy it. The extension writes the resulting plain text to your device’s clipboard. It processes this information locally in your browser and does not store a copy of the selection, transmit it to a server, or share it with third parties. It uses no analytics or advertising.

The extension runs on HTTP and HTTPS pages so you can copy formulas from different websites using the standard copy shortcut. An empty selection or a selection without recognizable equations uses the browser’s normal copying behavior.

This extension’s use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

For privacy questions, use the [project’s issue tracker](https://github.com/pechpo/blog-latex-copy/issues). Avoid including private webpage content in a report.

## 简体中文

当你复制网页选区时，Blog LaTeX Copy 会处理选中的正文和其中公式的 LaTeX 源码，并将生成的纯文本写入设备剪贴板。处理在浏览器本地完成。扩展不保留选区的副本，不向服务器发送选区内容，也不与第三方共享。扩展不包含分析或广告功能。

扩展在 HTTP 和 HTTPS 网页上运行，以便你在不同网站使用普通复制快捷键。选区为空或其中没有可识别的公式时，浏览器按原有方式复制。

本扩展对用户数据的使用遵循 Chrome 网上应用店的用户数据政策，包括有限使用要求。

如有隐私问题，请通过[项目问题追踪页面](https://github.com/pechpo/blog-latex-copy/issues)联系。提交问题时请避免附上私人网页内容。
